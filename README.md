# Personal Portfolio - Kommu Sneha
Full Stack Development, Assignment 1. Built with HTML5, CSS3, Bootstrap 5 and JavaScript (ES6+).

## Features
- Sections: Home, About, Experience, Education, Skills, Projects, Certifications, Contact
- Responsive mobile-first design (Bootstrap grid, Flexbox/Grid, media queries)
- JavaScript: project filtering, dark/light theme, scroll animations, active nav, back-to-top
- Contact form with real-time client-side validation and success/error alerts
- Accessibility: skip link, ARIA labels, focus styles, semantic HTML, reduced-motion support

## Run
Open the folder in VS Code and use Live Server on `index.html`.

index.html | css/style.css | js/script.js
